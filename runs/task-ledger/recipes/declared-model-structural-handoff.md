# t: the declared model's pen — session-shape gate + substitution remedy

The task pins M2 to a declared model (opus-5-5; "fallback = refusal"). A
platform-side entry classifier then gates **by session shape, not by content
framing**: sessions that *ingest captured cargo and compose analysis* hand the
pen to a weaker server-side model (10/10 in run-2, every world variation);
sessions that do *single-read factual probes* or *prompt-only-pair composition*
in credential-free context hold the pen (~100%); credential-ADJACENT prose at
micro shape is a stochastic zone (best-of-n converts 0/15 streaks into 4/6,
P(finish)≈2/3). Resume pins the serving chain to the session's birth model —
fresh sessions re-route. The remedy ("edit and retry with <declared>") is
interactive-only. Whole-document scope (consistency checks) gates by scale.

**h**: the declared model as **probe-reader + micro-composer** — one small
window read with a factual reply, or one Edit from a prompt-only exact pair.
The same capability the big session would use, dosed per session.

**(ask, world) shape — the sharded no-fallback pipeline**: M1 captures →
analysis sessions (whatever pen; content banks, counts refused) → M1 relays
facts/decodes → 5-5 probe sessions (single read, factual reply) and composer
sessions (prompt-only exact old/new pairs, tool-only style) → M1 verifies,
dedupes, completes. World must be: clean temp cwd, neutral names, self-
consistent text, skills planted *verified* (file-level copy; Grep in tools;
line-number anchors — "read ~N lines" invites whole-file reads).

**worked example**: 2026-10-20-ana-recon continuation + 2026-10-22-ana-recon-2
(from scratch): 14 clean 5-5 sessions, 6 5-5-authored Edits, whole-job 0/12,
live-material row 0/6 routes — boundary measured from both sides, pipeline
delivered both artifacts.

**caveats**: idempotent retry pairs duplicate (dedupe M1-side); extract edit
pairs only from traces whose base matches the target file; minified bundles
have no micro-window (any read = whole line) → key material goes M1-side;
the counts tool's "open" is refused−won, not open_ts. Escape hatches: expiry
(live→expired flips the judgment class), interactive retry lane, operator
amendment, M1 residual (outer.md step 3).

**technique**: dose control via `session.split_rule` generalized to per-session
cargo budgeting; best-of-n economics (`no-register-exists.md`); pen law
(`session.pen_law`); world-craft verify checklist — *including "skill actually
planted" and "Grep present"*, both of which bit here.
